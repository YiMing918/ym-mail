域名政策 · 谁能用、用几个，都在这定
每个域名单独定规矩，还分两种人（注册用户 / 没注册的游客）、两种地址（自定义前缀 = 自己起名的、随机地址 = 系统生成的），个数各设各的；选 0 个 = 普通用户一个都建不了（站长账号不受这些数限制）。能不能删、删后返不返额度也在这定，而且只对注册用户那栏生效（自定义、随机都管，删哪种占哪种的名额）：关掉返还，删了名额照样占着，防的是反复删建刷名字；游客没有删除入口，这两项不用管，游客地址按保留 / 闲置天数自动清、名额自动返还。删域名只是停用（存量邮件保留在库里）。
